Detailed Description

Vulkan hardware-accelerated canvas based on Qt 6 QRhi (Rendering Hardware Interface).

VulkanCanvas replaces legacy OpenGL with Qt 6's QRhi targeting the Vulkan graphics backend. Vertex and fragment shaders are compiled ahead-of-time from GLSL into SPIR-V bytecode bundles via Qt's qsb tool and embedded directly into the binary as Qt resources with the .qsb extension under :/shaders/vulkan/. No runtime GLSL compilation or driver-level shader parsing occurs at runtime.

It provides a decoupled GPU abstraction layer (Gpu namespace) that enables the document view to record draw operations, stencil masks, and shader uniforms without exposing raw Vulkan or OpenGL handles. Transparent UI elements (text, hints, borders) are rasterized via QPainter into an ephemeral pre-multiplied alpha image and composited over the Vulkan swapchain using hardware blending.
