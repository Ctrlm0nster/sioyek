Detailed Description

Concurrency engine and multi-threaded MuPDF rasterization subsystem.

PdfRenderer orchestrates asynchronous, multi-threaded document rasterization and text searching using MuPDF 1.26.11. To ensure high rendering throughput and low latency:

  • Context Cloning: Each worker thread operates on its own cloned fz_context sharing master allocator and locks, eliminating thread contention inside MuPDF.
  • Condition Variable Synchronization: Workers wait on render_work_ready and search_work_ready condition variables rather than busy-polling or sleeping, waking immediately when new requests arrive.
  • Speculative Pre-rendering: Pages along the active reading direction are queued speculatively when workers are idle, but can be preempted or discarded if navigation changes.
  • Epoch-based Cache Invalidation: Thread-safe document lifetime management uses fz_keep_document/fz_drop_document and a monotonic document_epoch counter to safely drop stale or cancelled raster jobs without race conditions.
  • Event-driven Readiness: Completed raster passes emit render_advance() to notify the GUI thread and advance waiting IPC commands without periodic polling.
