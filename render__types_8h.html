Detailed Description

Core types and CPU-side raster image registry for Sioyek's rendering subsystem.

Sioyek completely decouples multi-threaded MuPDF CPU rasterization from Vulkan GPU presentation. Worker threads render pages and page slices into CPU-side QImage instances and register them into the RenderImages registry with a unique RenderHandle. The GUI thread retrieves these images on demand and uploads them to GPU textures via VulkanCanvas and QRhi, ensuring that worker threads never invoke GPU or windowing system APIs.
