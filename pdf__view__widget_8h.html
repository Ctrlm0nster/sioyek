Detailed Description

High-performance document display widget with Vulkan hardware acceleration and lookahead.

PdfViewWidget implements the interactive PDF viewport. It bridges the document model, the PdfRenderer concurrency engine, and the Vulkan presentation canvas.

Key features:

  • Coordinate Systems: Seamless conversions between NormalizedWindowPos ([0, 1] window space), DocumentPos (page-relative space), and AbsoluteDocumentPos (continuous vertical document space).
  • Slice Calculation: Subdivides dense pages into dynamic tile grids (nh x nv) at high zoom levels to avoid single-texture GPU allocation limits and raster bottlenecks.
  • Directional Lookahead: Tracks navigation velocity and scroll direction in update_navigation_state() and issues speculative render jobs via maybe_trigger_lookahead() ahead of viewport movement.
  • Interactive Overview: Floating portal overlay rendering separate document locations using stencil clipping, custom scaling, and synchronized search highlights.
